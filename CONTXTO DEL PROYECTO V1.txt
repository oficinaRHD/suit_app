# SUIT - CONTEXTO COMPLETO DEL PROYECTO

## 1. IDENTIDAD
- Nombre: Suit
- Tipo: Plataforma B2B de gestión de ventas y vales (vouchers)
- Público: Agentes/Managers + Proveedores
- Valor: Conexión entre red de distribución y proveedores

## 2. ROLES Y FLUJOS

### MANAGER / AGENTE
- Archivos: home-managers.html, vouche.html, histori-vouche.html, supplier-managers.html, settings.html
- Acciones:
  - Crear vales (con documentos ID frontal+posterior)
  - Ver historial de vales creados
  - Vincular proveedores mediante código
  - Gestionar perfil y configuración
- Flujo vale: Manager crea → adjunta ID cliente → envía a proveedor

### PROVEEDOR
- Archivos: home-supplier.html, histori-vouche-receive.html, manage-managers.html, settings.html
- Acciones:
  - Recibir vales pendientes de aprobación
  - Aprobar/rechazar con chat integrado
  - Ver historial de vales recibidos
  - Gestionar solicitudes de vinculación de managers
  - Aprobar/rechazar managers que solicitan enlace

### USUARIO GENERAL
- Archivos: login.html, signup.html, index.html
- Landing pública con dos CTAs: Acceso Proveedores / Acceso Gestores
- Registro con selector de tipo de cuenta (provider/manager)
